## 📌 Featured Product, Analytics & Experimentation Work

### 📊 [Fintech Product Lifecycle Analytics](https://github.com/kowshikkkkkk/fintech-lifecycle-analytics/tree/main) `Public Data · 2.56M Events · A/B Design`
Mapped end-to-end user activation and drop-offs across 2.56 million events—identifying a drop from **44% app open to 2.7% first deposit**. Designed a targeted reminder A/B test and authored two full PRDs.

### 🛒 [Retail Behaviour Analytics](https://github.com/kowshikkkkkk/retail-behaviour-analytics) `Segmentation · Experimentation · A/B Simulation`
Segmented 5,014 shopper accounts using RFM—revealing the **top 10% drove 36.6% of total spend**—and simulated A/B tests to demonstrate how underpowered experiments produce misleading false positives.

### 📈 [ChronosGame](https://github.com/kowshikkkkkk/chronosgame-player-forecasting) `Time Series · Causal Inference`
Built 14-day player forecasts across 5 Steam titles achieving **7–13% lower error** than baseline models; ran placebo tests proving no statistically reliable lift from Steam sales.

### 🏥 [TrialPulse](https://github.com/kowshikkkkkk/clinical-trial-dashboard) `Hackathon Data · Multi-Agent`
Scored **57,997 subjects across 23 clinical studies** (207 files) on a custom data-quality index, paired with an interactive React dashboard and three autonomous LLM agents.
